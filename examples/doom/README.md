# Does it run doom?

No idea, it can draw it though :D

***WARNING***: This code performs *RAPID* full screen redraws on the Beacn
Mix Create screen (20fps). This shouldn't cause a problem, but I have no idea
how the screen or firmware will react to being used in this way. I've seen 
devices lock up.

You'll probably wanna run this in `--release` mode, CPU gets a bit heavy in debug.

Controls:

`AudienceMix` - Walk Forward  
`Dial 4 Turn`: Turn Left / Right  
`Dial 4 Press`: Shoot  
`Dial 4 Button`: Use
